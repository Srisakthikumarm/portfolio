# 🚀 Sri Sakthi Kumar M — Interactive UI/UX & Frontend Portfolio

A high-performance, glassmorphic portfolio website and interactive Cyber Defense web application for **Sri Sakthi Kumar M** (UI/UX Designer, Product Designer, and UI Developer).

Built with **React 19**, **Vite**, **Bootstrap 5**, **Material UI**, and custom HTML5 Canvas retro game engine.

---

## ✨ Features

- **🎨 Modern Glassmorphic Design System:** Custom HSL dark mode, glowing accents, glass cards, and smooth section transitions.
- **🛡️ Full-Site Cyber Defense Retro Game:** Playable interactive arcade game overlay (`FullSiteRetroGame`) that spans across the entire website with touch joystick controls and desktop key bindings.
- **📱 100% Mobile & Cross-Device Optimized:** Dynamic layout calculations, touch-friendly interactive buttons, and responsive breakpoints.
- **⚡ High Performance:** Zero layout-thrashing, cached DOM offsets, and 60fps canvas rendering loop.

---

## 🛠️ Local Setup & Run

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```
