📁 SECTION 3: PROJECT TEMPLATES FOR MANUALLY ADDING/EDITING PROJECTS

Open src/components/Projects.jsx (or src/components/AllProjects.jsx) and use the three simple templates below:

1️⃣ TEMPLATE FOR A COMPLETED PROJECT (WITH ALL LINKS):

{
  id: "my-completed-project",                           // Unique name (e.g. "fitness-app")
  title: "YOUR COMPLETED PROJECT TITLE HERE",            // Project Title
  year: "2026",                                        // Year
  inDevelopment: false,                                // Completed = false
  desc: "Short 1-2 line description of your project.",
  fullDetails: "Detailed writeup for the View Details modal popup window.",
  tech: ["FIGMA", "REACT", "UI/UX DESIGN", "PROTOTYPE"],
  image: "/assets/your_image_name.jpg",                 // Image inside public/assets/
  
  // Link Buttons (Leave as "" if you don't have a link):
  link: "https://www.behance.net/gallery/your-link",
  behanceLink: "https://www.behance.net/gallery/your-link",
  mediumLink: "https://medium.com/@your-link",
  dribbbleLink: "https://dribbble.com/shots/your-link",
  figmaLink: "https://www.figma.com/design/your-link",
  githubLink: "https://github.com/your-repo-link",
  demo: "https://your-live-demo-website.com",
},

2️⃣ TEMPLATE FOR A NEW UNDER-DEVELOPMENT PROJECT:

{
  id: "my-dev-project",                                // Unique name
  title: "YOUR UNDER DEVELOPMENT PROJECT TITLE",        // Project Title
  year: "IN DEVELOPMENT",                              // Year tag
  inDevelopment: true,                                 // inDevelopment: true (Shows IN DEVELOPMENT badge!)
  desc: "Brief description of the product currently under active design and development.",
  fullDetails: "Detailed roadmap and progress summary of this project.",
  tech: ["FIGMA", "DESIGN SYSTEM", "B2B UX", "IN DEVELOPMENT"],
  image: "/assets/your_dev_image.jpg",
},

3️⃣ HOW TO CONVERT AN UNDER-DEVELOPMENT PROJECT TO A COMPLETED PROJECT:

// BEFORE (Under Development):
inDevelopment: true,
year: "IN DEVELOPMENT",

// AFTER (Completed! Just change inDevelopment to false and update the year):
inDevelopment: false,
year: "2026",
link: "https://www.behance.net/gallery/your-new-completed-link",
behanceLink: "https://www.behance.net/gallery/your-new-completed-link",
