📁 SECTION 1: HOW TO ADD A NEW PROJECT TO YOUR WEBSITE

To add a new project card to your portfolio:

  1. Place your project image inside the public/assets/ folder (e.g. my_new_project.jpg).
  2. Open the file: src/components/Projects.jsx (or src/components/AllProjects.jsx).
  3. Copy the template block below, paste it inside the featuredProjects list, and fill in your details!
/* 
=================================================================================
  NEW PROJECT TEMPLATE: COPY & PASTE THIS BLOCK TO ADD A NEW PROJECT
=================================================================================
*/
{
  id: "my-new-project-id",                              // 1. Unique ID (e.g. "mobile-app-design")
